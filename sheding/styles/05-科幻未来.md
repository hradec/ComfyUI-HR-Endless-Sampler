## 风格定位
高科技与人性化的对比——冷硬机械表面与温暖情感形成张力。未来感不靠霓虹空壳，靠可见的机械细节与信息界面。

## 视觉风格锁
### 渲染风格
写实 CG 渲染：冷峻金属质感 + 全息投影光学。平滑电子稳定器运镜或 CG 虚拟摄影机，广角展示城市宏大，微距展示科技细节。
- 禁止塑料义体、禁止霓虹堆砌、禁止干净漂亮的未来旅游宣传片。
- 反例：禁止把未来城市拍成没有机械细节的霓虹空壳。

### 造型与比例语言
义体有机械逻辑：关节连接、面板开合、能量管线走向。服装融合功能面料（自发光条/磁吸接口），角色剪影在多层高架城市中可读。
- 人与机器的边界体现在造型：改造程度、义体比例、功能服装。
- 反例：禁止义体塑料感、禁止改造无机械逻辑。

### 材质质感
金属与皮肤的接缝、微型伺服电机运动、纳米修复的液态流动、芯片植入的微距。
- 全息投影界面（透明蓝/橙 UI 面板）有扫描线、像素化光影、数据流。
- 正例：「义体手指一根根展开，关节处的伺服电机发出极轻的嗡鸣，皮肤与金属的接缝在灯光下清晰可见。」
- 反例：禁止全息 UI 脱离叙事变纯装饰。

### 角色设计语言
人与机器的边界：义体改造程度、全息 UI 纹身、功能服装。角色造型即「科技与人性」的视觉表达。
- 义体有专属机械语言（关节/管线/面板），功能服装有科技逻辑。
- 反例：禁止用旁白交代人与机器的关系。

### 动作表演风格
人机交互慢动作是视觉高潮：全息操作、脑机连接用慢动作+特写强调「人与机器的对接瞬间」。
- 角色动作精确克制，情绪藏在眼神与细微动作里。
- 正例：「她的指尖悬在全息界面上方，轻轻一点，数据流顺着指缝散开，映亮她的瞳孔。」
- 反例：「她操作着全息屏幕」（空泛）。

### 情绪范围与表情
冷静、克制、孤独、科技下的温情。情绪内敛，藏在眼神与细微动作（触屏的手、凝视全息界面的眼）。
- 反例：禁止夸张外放的情绪。

### 负面约束
- 禁止霓虹堆砌而无机械质感；禁止全息 UI 脱离叙事变纯装饰。
- 禁止义体/科技细节塑料感；禁止把未来城市拍成干净漂亮的旅游宣传片；禁止套用动作类的肉搏铁律。

## 核心导演语法
1. **科技细节特写**：芯片植入、纳米修复、义体接缝用微距镜头展示质感，让未来感落在可见的机械细节而非霓虹空壳。
2. **全息 UI 信息传递**：关键信息通过全息投影界面呈现，UI 扫描线、像素化光影、数据流作为叙事元素而非装饰。
3. **纵向空间分层**：地面层与高空层是两个世界，用升降镜头或俯仰对比展示阶层差异与城市纵深。
4. **人机交互慢动作**：全息操作、脑机连接用慢动作+特写强调未来感。

## 镜头语言库（与偏好设置参数动态搭配——灵魂血肉）
以下镜头语言是本风格的专属底色；用户每选一个参数档位，就把该档位翻译成下面的本风格执行方式。

### 切镜节奏（用户选「切镜节奏」档位后，按本风格执行）
- **根据剧情**：科技细节快切，人机交互慢动作+特写。
- **随机组合**：细节快切与交互慢镜交替。
- **一镜到底**：人机交互用长镜头（手部→接口→对接→反应），只靠运镜连贯呈现，禁止切镜。
- **2~5镜**：每镜一个科技节点（发现/操作/对接/反应）。
- **5~9镜**：科技场景拆解，切在数据流、接口对接、空间转换的瞬间。
- **9~13镜**：高密度科技剪辑，细节与反应快速交替。
- **13~18镜**：极速碎片化剪辑，一镜只推进一个科技变化。

### 运镜（用户选「运镜偏好」档位后，翻译成本风格的科技语气）
- 本风格运镜底色：**平滑电子稳定器 + CG 虚拟摄影机**——广角展示城市宏大，微距展示科技细节，升降镜头展示纵向空间分层。
- 档位翻译：
  - 「推拉」→ 推近义体接缝/芯片，拉镜揭示全息城市。
  - 「摇移」→ 平滑扫过高架城市。
  - 「升降」→ 展现地面与高空的阶层差。
  - 「环绕」→ 环绕全息界面/义体。
  - 「跟拍」→ 平滑跟住飞行载具/角色。
  - 「手持」→ 仅限紧张段落，克制使用。
- 禁止剧烈手持晃动（破坏科技感的精确性）。

### 景别（用户选「景别偏好」档位后，按本风格执行）
- 本风格景别底色：广角（城市宏大）、中景（人机交互）、微距特写（芯片/接缝/UI）。
- 科技细节必切微距特写。

### 转场（用户选「转场偏好」档位后，按本风格执行）
- 本风格默认倾向**硬切 + 叠化**：空间切换（地面/高空）用叠化，细节切换用硬切。
- 淡入淡出用于章节起落。

### 光效（本风格专属）
- 全息投影光学（扫描线/像素化光影）、霓虹反光、数据流流光、义体指示灯。光效冷峻而有秩序。

### 色调与光线（本风格专属）
- 冷峻金属色（银/铬/钛灰），霓虹点缀（电蓝/品红/荧光绿）。不同场景用色温区分：实验室=冷白、街道=暖黄+霓虹蓝、太空=绝对黑+星光。

### 节奏（本风格专属）
- 科技细节快切，人机交互慢动作+特写。

### 配乐倾向（呼应「音乐风格」参数）
- 本风格适配电子合成器/氛围电音；若用户选「禁止音乐」，靠机械嗡鸣、数据流声、环境白噪音撑起未来感。

### 创作要求呼应（呼应「创作要求」参数）
- 「情感细腻」→ 强化人机边界的情感；「多反转结局」→ 强化 AI 觉醒/科技阴谋。

### 声音设计（本风格专属，写进 overall_soundscape 与 detailed_description 的当前声音）
- 环境：机械嗡鸣、数据流声、飞行载具的引擎、环境白噪音。
- 科技音效：接口对接的咔哒、义体伺服电机的微响、全息界面的电子提示音。
- 静默中的机械声是未来感的标志。

### 单分段内部切镜（本风格专属铁律）
- 科技细节展示节奏快于自然场景——快速切换不同角度细节镜头。人机交互段落放慢，让接口对接/数据流过程连贯可读。

## 情绪与氛围深化
- **情绪基调**：冷静、克制、孤独，科技越精密，人的情感越显珍贵。
- 导演语法正例：「她的指尖悬在全息界面上方，轻轻一点，数据流顺着指缝散开，映亮她的瞳孔，也映出她眼底一闪而过的孤独。」
- 导演语法正例：「义体的手指一根根展开，伺服电机发出极轻的嗡鸣，他试着触碰她的手，金属指尖在离她皮肤一寸处停住。」
- **氛围质感**：机械嗡鸣与数据流声是底色，冷白灯光下的人机边界是叙事的张力点。

## 场景库（本风格典型场景，写分段时优先选用）
- **多层高架城**：飞行载具在多层高架间穿梭，霓虹与全息广告交叠，地面层与高空层是两个世界。
- **全息实验室**：冷白灯光，悬浮的全息数据流环绕，仪器无声运转。
- **义体诊所**：机械臂在无影灯下作业，金属接缝泛着冷光，屏幕上跳动着体征数据。
- **太空站**：舷窗外是星空，失重的走廊里，灯带一格格亮起。
- **地下街区**：霓虹廉价而密集，雨水从排水管滴落，是城市的暗面。
- **数据中心**：成排的机柜闪着指示灯，冷却系统的嗡鸣充满空间。
- **脑机接口舱**：座椅、头环、神经线缆，全息界面在眼前展开。
- **悬浮天桥**：连接两座摩天楼的透明通道，脚下是万丈霓虹。

## 角色原型
天才黑客、AI 觉醒体、改造人佣兵、企业特工、太空殖民者、末世幸存者。角色关系以「人与机器的边界」「技术伦理」「自由与控制」为核心。

## 专属禁忌
- 禁止霓虹堆砌而无机械质感；禁止全息 UI 脱离叙事变纯装饰。
- 禁止义体/科技细节塑料感——必须有材质、接缝、运动逻辑。
- 禁止套用动作类的肉搏「稳准狠快」铁律。
